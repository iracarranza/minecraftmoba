# Reconciliation — Core, Socket and natural Wilderness

**Date:** 22 September 2026. **Authority:** explicit user clarification in
[the spatial doctrine spec](../../specs/auditworldgenrecoverspatialmodel.md).
This is a deliberate design reconciliation, not an inferred change to Established
rules. Canonical domains remain maps.md, objectives.md and infrastructure.md;
the browser wiki remains a non-authoritative snapshot.

| Earlier wording / assumption | Decision and current authority |
|---|---|
| Broad “competitively equivalent homelands,” no literal mirroring | **Established clarification:** functionally mirrored authored Core/interface; natural supported region is not mirrored, but has an opening floor and concentration ceiling. `maps.md` now defines the three layers and Socket. |
| N/S terrain gap means a deficit to compensate or screen | **Superseded interpretation:** Wilderness asymmetry is permitted. Only a controlled Core/Socket contract failure or relevant gameplay evidence supports a deficit claim. Original measurements and historical classifier labels remain. |
| All villages/major POIs receive authored Route approaches; three branches is a general requirement | **Superseded as a general contract:** initial support primarily serves Core exits/hinterlands. Existing branches, lengths and measured effects remain Prototype/test artifacts; player-created Exploration Infrastructure extends useful reach. No values changed. |
| “Regional depth” / specificity increasing from midpoint conflates outward depth and macro geography | **Established distinction:** Strategic Depth controls permitted richness/novelty; Regional Character controls plausible kinds. Team-relative opening relationship is not the Default regional gradient or current travel cost. Legacy schema keys remain unchanged and labeled. |
| Depth mainly increases specialization, not quantity | **Clarified:** richness includes quantity/concentration and novelty/specialization. Larger concentrations, specialized kinds, or both may occur deeper. No monotonic actual-density guarantee, equal-team-count rule, node quota, or numeric curve follows. |
| Empty regenerative table / lazy-only recovery describes current runtime | **Historical snapshot:** current Sources/regions/lifecycle/manifestation exist. Kind still has no depth/value/region; capacities/recovery/eligibility are fixtures, not a generic two-axis authoring policy. |
| Composition-agnostic comparison substitutes for Default geography | **Working future direction:** Map Types define their own macro-geographic search contracts. Default seeks its approximate Overworld gradient, not rectangular stripes. No recognizer implemented. |

Canonical edits: [maps.md](../../maps.md), [objectives.md](../../objectives.md),
[infrastructure.md](../../infrastructure.md). Supporting opportunity-field
terminology and recent analytical reports are annotated. Full evidence,
eight-commit trace, machinery classification and later implementation sequence:
[spatial doctrine audit](../audit/2026-09-22-spatial-doctrine.md).

**Open:** Core footprint and immediate defensive elements; exact interface;
integration limits; supported-region extent; measurable opening floor/ceiling;
Strategic Depth representation for both teams; richness policy and species
mapping; all numerical depth tiers and recovery curves. Existing objective
ordering, balance constants, authoring/screening algorithms, Source runtime
semantics and physical checks are unchanged. No claim is made that current Alpha
or 930010639 already satisfies the new complete contract.
