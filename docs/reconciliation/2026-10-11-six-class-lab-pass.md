# Six-class lab pass decisions — 11 October 2026

The owner requested the five numbered priorities, which include six classes:
Hollow, Paver, Fungal Assassin, Chauffeur, Bloodmason and Quarryman. Existing
`classes.md` status labels remain in force. Hollow's supplied definitive design
is incorporated in §30; its health and return curve are authored, other unspecified
magnitudes remain Prototype/test.

The owner explicitly settled three questions before dependent implementation:

- Fungal Assassin Airborne Spread widens the enemy-hit radius, not the created
  Mycelium territory.
- Paver Pitons has two anchors. Initial use places the first, first recast places
  the second; subsequent recasts dash to the farther anchor from current position.
- Hollow Soresight counts unique enemies damaging Hollow during Wooden Maw;
  this supersedes aim/attention-based targeting.

Remaining lifecycle, geometry and parameter choices are lab prototypes and must
be recorded with delivered validation. No unresolved class Growth/Task/infrastructure
eligibility is promoted by registration. No stale browser wiki is design authority.

Implementation choices are recorded in
[the six-class lab pass](../design/SIX_CLASS_KIT_LAB_PASS.md). In particular:

- Submersive uses native Kelp as a water-column prototype; canonical waterlogged
  vine presentation remains a fidelity question, not a redesign.
- Bloodtrail writes the effective contacted footprint for this experiment;
  nominal/effective amplification remains Open. Native anatomical materials,
  staged room geometry and contained lava do not settle final art/topology.
- Quotas use a prototype one-minute refresh, Stage 1–12 and demand `20 + 10*(Stage-1)`.
  Scan is ceil-rounded and block-anchored, capped at width 15. Strike chooses the
  strongest carried base pickaxe tier. Clear does not count as failure or success.
- Eternity Mountain uses a native runtime domain, real mountain player and an
  owned World-body proxy, two-second telegraph plus recast, native mining setup
  sampling, hardness ordering and conservative structural/container protection.
- Chauffeur real vehicles are implemented; generalized vehicle recognition and
  commitment are not claimed by the existing Skeleton Crew Supply Line adapter.
- No missing Growth/Task eligibility is inferred from archetype or roster entry.
  Hollow's supplied Growth health/Heart return curve is the authored exception.
- Retained ultimate glow uses shared public leases. The separate per-viewer
  empowerment contract remains Open, preserving the repository's distinction.

These are **Prototype/test** choices. Established shared damage/status,
provenance and reservation rules continue to apply. Java 21 and native Bukkit
runtime authoring reuse the existing lab/domain implementation approach; no
playable map build or canonical map-authoring decision is introduced.
