# Claude map-authoring handoff

Start with claude-authoring-handoff.json, then read scenario-frontier.json and candidate-catalog.json.

## Source of truth

The committed optimizer and generated artifacts are one v2 provenance chain. Do not use older reference numbers from historical commits. Existing exact authored worlds/rescans are tied to pre-v2 frontier hash 444594cd... and are historical validation evidence only.

## Non-negotiable hazard rule

The export's zero-hostile entity snapshot is **not evidence of safe caves**. Underground hostile exposure remains **UNRESOLVED**.

## V2 Route rule

A Route is a spatial economic intervention, not just a connection to its target. During authoring, record every crossed or nearby opportunity and rescan all Practical Reach. The optimizer's regional spillover estimate is a screening sensitivity, not a substitute for the exact authored corridor.

## Workflow

1. Use preferred v2 finalist rank 0 for the selected profile; use listed fallback ranks if exact terrain invalidates it.
2. Author exact founder patches, renewable ranges, generic dormant Worksites, POIs, Route targets, and physical Routes.
3. Preserve ecological eligibility and the no-speed-bonus Route rule.
4. Record full Route crossing metadata, not only crossing kinds.
5. Rescan the exact authored world and compare all balance components against both raw and spillover-sensitive regional estimates.
6. Do not freeze any profile until exact-world values replace regional estimates.
