# Claude map-authoring handoff

Start with `claude-authoring-handoff.json`.

Everything required to regenerate the regional authored-opportunity search is repository-resident: the realized-map export, optimizer, design rules, reference-run results, and hostile-data guard.

## Non-negotiable warning

The export's zero-hostile entity snapshot is **not evidence of safe caves**. Underground hostile exposure remains **UNRESOLVED**. Do not feed zero hostile pressure into Extraction or 7v7 economic conclusions.

## Workflow

1. Read the export README and the authored-opportunity optimizer design document.
2. Run the exact commands in `claude-authoring-handoff.json`.
3. Confirm the candidate-space/reference-run shape before authoring.
4. Inspect multiple balanced profile finalists rather than treating one configuration as the universal optimum.
5. For a selected finalist, inspect the real terrain inside each 128x128 candidate region and choose block-exact placements.
6. Preserve the strategic relationship encoded by the finalist. Exact aesthetics/terrain fit may vary; strategic geography should not be improvised.
7. Author physical Routes rather than speed buffs.
8. Keep dormant Worksites generic before activation.
9. Rescan every exact site/path after authoring.
10. Rerun non-combat balance with exact measurements. Do not freeze the map while regional reach proxies are still standing in for exact authored geometry.

## Strategic profiles

The current tool searches Balanced Baseline, Exploration-Centric, Consolidative, Resource-Dense, Resource-Light, Contested Core, Peripheral Specialization, and Route-Centric configurations.

These are different match characters, not rankings. Current counts, profile weights, and the 0.12 structural-balance filter are analytical fixtures rather than canon.

## Exact-world validation

Regional reach interpolation has roughly 7–8% median relative leave-one-out error in the reference pass (about 9.6 s North and 7.5 s South median absolute error). It is for candidate ranking only. Local terrain can deviate substantially, so block-exact authoring must always be followed by a measured rescan.
