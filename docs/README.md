# Documentation

The canonical domain documents remain at repository root for compatibility:
`classes.md`, `objectives.md`, `maps.md`, and `infrastructure.md`.

`manuscript/` contains the editable chaptered design synthesis in Markdown and Word.

`reconciliation/` records audits, source conflicts, and explicit decisions.
`history/` is reserved for archived handoffs and retired material when it is
eventually moved out of the repository root.
