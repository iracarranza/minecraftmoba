Class schema 
{
  "type": "class",
  "version": 1,
  "id": "redstoner",
  "name": "Redstoner",
  "status": "Working draft",
  "archetypes": {
    "primary": "Production",
    "secondary": ["Construction", "Combat"]
  },
  "coreIdea": "One-sentence class identity.",
  "passive": {
    "name": "Passive name",
    "description": "..."
  },
  "abilities": [
    {
      "name": "Ability 1",
      "description": "...",
      "upgrades": [
        {"name": "Upgrade A", "description": "..."}
      ]
    }
  ],
  "ultimate": {
    "name": "Ultimate",
    "description": "..."
  },
  "buildDirections": ["Direction A"],
  "openQuestions": ["Question A"]
}
Generic schema for other pages 
{
  "type": "objective",
  "version": 1,
  "id": "example-objective",
  "name": "Example Objective",
  "status": "Working draft",
  "summary": "Short canonical description.",
  "sections": [
    {
      "heading": "Rules",
      "body": ["First rule", "Second rule"]
    }
  ],
  "openQuestions": ["Question A"]
}

The same generic shape works for map_archetype, mechanic, item, balance_note, and idea.
