Procedural philosophy

Maps should combine procedural generation with distinct map archetypes.

A map archetype defines the fundamental geometry and strategic problem. The seed determines the exact terrain, resources, routes, structures, and opportunities inside that grammar.

Players should learn Minecraft generation rules and how an archetype behaves without memorizing fixed resource coordinates. The competitive skill test includes rapidly reading an unfamiliar Minecraft world and deciding how the team should transform it.

Working generation model

Default map

The Default map should remain recognizably based on actual Minecraft Overworld generation, including underused or ordinarily low-value generation quirks. It is not one fixed map.

Mirrored homeland

Generate one baseline starting territory and mirror it for the opposing team. The homeland contains the ordinary resources necessary to begin playing Minecraft: common terrain materials, wood, food, baseline ore access, useful caves, development space, the Aether Fountain, and team defensive objectives.

Literal mirroring is acceptable here because these are baseline resources rather than jackpot opportunities. Early play tests what teams do differently with comparable starting material.

Continuous wilderness

Outside the homelands is one continuous procedurally generated Overworld rather than rigid A-side, center, and B-side bands.

The wilderness contains the meaningful exploration layer: villages, natural structures, unusual geology, richer deposits, biome-specific resources, transportation opportunities, and neutral objectives. High-value resources and POIs should generally not be literal mirrors.

Mirrored value, not mirrored generation

Competitive balancing should compare the strategic opportunity available to each team without requiring identical terrain or POIs.

POIs can be assigned multidimensional value profiles rather than one universal score—for example Extraction, Development, Production, Exploration, Logistics, and Combat value. Loot tables and surrounding resources can be adjusted where useful to balance an otherwise strong seed.

  1. Baseline — literally mirrored starting access.
  2. Allocated opportunity — independently generated content with comparable strategic value available toward each side.
  3. Contested opportunity — a single shared POI whose fairness comes from comparable discoverability/access rather than duplication.

Players do not see generator value scores.

Working

Villages

The wilderness should contain enough villages for discovery to become a network problem rather than a single lookup.

Current target: at least 3 wilderness villages, with roughly 3–5 possible in a Default match.

Three is the minimum at which players can discover settlements in different orders, compare their economic value, develop different villagers, and build meaningful inter-settlement routes. Additional villages must remain sparse enough to feel discovered rather than ubiquitous.

Vanilla generation legality is not sufficient for match design. Even if villages may legally generate relatively near one another, the map should generally allow substantially larger effective separation—often hundreds of blocks, with terrain further changing travel difficulty.

Working / unresolved

Scale

Earlier working footprint: approximately 1,300 × 1,000 blocks, with Aether Fountains roughly 900–1,100 blocks apart. These numbers are prototype targets, not canon.

The previous concept of narrow ~200-block wilderness bands is superseded. Most territory outside the mirrored homelands is continuous wilderness, which gives several villages and lesser POIs enough space to function as genuine exploration discoveries.

Scale should be locked only after testing movement speed, match duration, POI density, and how strongly player-created routes compress effective distance.

Working

Seed selection / validation

A useful precedent is Minecraft speedrunning seed filtering: let Minecraft generate Minecraft, then inspect whether a seed/region is suitable for competitive play.

generate terrain → locate/classify POIs → establish mirrored homelands → evaluate regional opportunity → adjust loot/resources where appropriate → place competitive objectives → validate → accept/reject

Different map archetypes may eventually function partly as different generation/seed-selection contracts rather than wholly separate handcrafted terrain generators.

Working direction

Underused Overworld generation

Default should particularly value Minecraft features that ordinary survival often underuses or quickly outgrows.

Candidates include desert wells, fossils, igloos, swamp huts, ruined portals, ocean ruins, trail ruins, geodes, mineshafts, monster rooms, unusual cave/aquifer formations, and biome-specific terrain quirks.

These should retain their Minecraft identity. Classes and systems can create additional reasons to care about them rather than replacing them with generic MOBA camps or tokens.

The source document points to WORLD_VOCABULARY.md for the broader resource/feature coverage audit.

Working archetypes

Map archetypes

Valley / Default

Balanced baseline. Ordinary Overworld terrain and generation. All avenues broadly viable; strategic variation comes from the seed rather than a fixed arena.

Chasm

Vertical ravine/cavern geometry emphasizing bridging, cliff routes, tunneling, and vertical transportation. Problems should admit multiple Minecraft solutions: across, around, through, or down.

Archipelago

Water-separated resources and objectives. Boats, bridges, underwater tunnels, docks, ice routes, and potentially later advanced transportation make logistics central.

Underdark

Predominantly underground and initially unknown. Cave reading, tunneling, lighting, sound, and verticality dominate. Player-created tunnels may effectively become the match's lanes.

Canopy

Large forest/jungle with canopy, ground, and underground layers. Encourages three-dimensional route networks.

Wastes

Scarcity-focused desert/badlands/volcanic family. Renewable resources, settlement expansion, wood/food access, and concentrated deposits matter more.

Map archetypes should foreground different Minecraft traversal/building techniques without arbitrary class bonuses such as “+20% Mole power on cave map.”
